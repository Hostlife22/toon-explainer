# 09 · Directing: from a topic to a film that plays as a story

Read this **before** writing a storyboard or a spec. It turns a topic into a sequence of visible events, then into shots. The other guides answer "which layer draws this"; this one answers "what should happen on screen, and why in this order". The rules come from a full study of 20 reference videos (8 long, 12 vertical shorts; coverage in [06-reference-library.md](06-reference-library.md)); the techniques it names are catalogued by purpose in [10-technique-library.md](10-technique-library.md), and the vertical format is in [11-vertical-shorts.md](11-vertical-shorts.md).

The pipeline:

**topic → central question → story arc → meaning events → visual actions → characters and locations → timing → check → render**

Do the steps in order and write each one down (a few lines in `script.md` above the first shot is enough; see [`examples/vertical_short/script.md`](../examples/vertical_short/script.md)). Skipping straight from facts to shots is what produces a slideshow.

## 1. Topic → central question

Write one question the film answers, phrased so that a viewer wants the answer:

| Weak (a subject) | Strong (a question with tension) |
|---|---|
| "Ice" | "Why does frozen water float when almost every other frozen thing sinks?" |
| "The Reconquista" | "How does a war last 781 years?" |
| "Vaccines" | "How do you train an army for an enemy it has never met?" |
| "Inflation" | "Why does printing more money make everyone poorer?" |
| "Password security" | "How can a stranger guess your password without ever seeing it?" |

The reference videos all open on such a question or a paradox: China is "only called China since 1912"; the Reconquista promises 781 years "in 15 minutes"; a short claims "almost everything shrinks when it freezes" and then breaks the rule. If the topic is a list of facts, find the conflict hiding in it: X against a problem, the old way against the new, expectation against reality, a rule against its exception.

## 2. Central question → story arc

Pick one arc shape and write its beats as one line each. These are the shapes the references use:

| Arc | Beats | Fits |
|---|---|---|
| **Broken rule** (shorts, science) | rule → the exception shown → mechanism → consequence → what-if → payoff | "why does X behave strangely" |
| **Cycle** (dynasty history) | rise → flaw → collapse → counter goes up → new unifier; repeat 3–7 times, each pass faster | anything that repeats: market bubbles, product hype cycles, epidemics |
| **Escalation ladder** | the same request or attack three times, each answered with a stronger reaction, the third breaks something | appeasement, scope creep, a bully, a bug that grows |
| **Case loop** (fact-check) | claim → verdict → 1–4 cutaways of reality → back to the judge; later cases run faster | myths vs facts, product claims, rumours |
| **Myth / drama arc** | setup → sin or mistake → curse → escalation → payoff → consequence | a founder's story, a scientist's obsession, a disaster |
| **Chapter per actor** | one actor per 30–60 s, each with a name card, one defining gag and an exit | "who built X", rival companies, the players in a crisis |
| **Mechanism** | normal state → an agent acts → hidden step made visible → new state → why it matters | how a vaccine, an engine, a market or an algorithm works |

A long film combines a frame device (museum, game, trial, storyteller; see [07-story-craft §3.2](07-story-craft.md)) with one arc per chapter. A short uses one arc with 4–6 steps and one twist ([11 §5](11-vertical-shorts.md)).

## 3. Arc → meaning events

A **meaning event** is one thing the viewer must understand, stated as a change: "the ruler loses the right to rule", "water molecules lock into rings", "the bank runs out of cash". List them in order, 1 per 4–8 s of narration for shorts, 1 per 6–15 s for long films. Then mark each one:

- **C** (cause): it makes the next event happen; the next shot must show the effect.
- **Q** (question): it raises something the viewer now wants answered; the answer comes later and must be paid off.
- **T** (turn): it reverses an expectation ("but", "until", "instead").
- **S** (stakes): it shows what is lost or gained.

If two events in a row carry no mark, merge them: they are one event. If a turn has no setup earlier, add the expectation it reverses.

## 4. Meaning events → visual actions

For every event, find the **physical action** that shows it, before choosing any layer. Ask in this order:

1. **Can a character do it?** Abstract processes become people or objects acting: territories with arms push borders; molecules hold hands; debt is a sack that slides back; a "popularity elevator" lifts a leader as the money bar drains (WW2 12:50). Use `bean`, `obj` with a `face` and `arms`, map regions with faces.
2. **Can the idiom be literal?** "Meat grinder" (China 18:20: a ruler cranks soldiers into a sausage that hits barbed wire), "puppet ruler", "stabbed in the back", "a lid on the lake". Draw the words ([07 §4](07-story-craft.md)).
3. **Can a known system stand in for it?** A game evolution screen for a promotion (China 7:00), an upgrade button for a policy (China 27:48), a checklist re-titled "TO DO LIST" for a broken treaty (WW2 13:14), a stat device with two bars for a character profile (China 16:14). Draw the system in your own design; never copy a real game or brand.
4. **Can the cause and the effect share one frame?** The bribe bag lands and the general stabs his own side (China 6:26); a checklist strike moves the army on the map on the same frame (Fact-check 2:53). Put the cause object and the effect in one composition, or in two consecutive shots with the same screen direction.
5. **Only then:** a label, a counter, a chart. Text names what the action already shows; it does not replace it.

Write the action as **subject + verb + visible result**: "the ice block rises past the label LESS DENSE", not "explain density".

## 5. Visual actions → characters and locations

- **Cast once** in `spec.cast`: each recurring character gets one silhouette cue (hair, hat, outfit colour) that survives a 60-px thumbnail. Roles read through scale and costume: a child for a demanding aggressor (WW2 13:34), a brute build for raw power, a labcoat for the expert, a crown that appears and disappears.
- **A host or a witness.** Long films keep a narrator character who re-costumes per chapter (WW2: the same host as Italian, Bavarian, Japanese) and a mute viewer stand-in who collects stickers as rewards. Shorts keep the host off screen or as a 2–4 s reaction insert.
- **Few locations, reused in changed states.** A hub set returns (a piazza sunny, then stormy and grey for decline; a palace door with shadows rising, later with a GET OUT sign; a storehouse full, then cobwebbed). The change of state *is* the information. Budget: a 60 s short uses 4–7 sets; a 10-minute film 15–25.
- **Every set gets three planes** ([02 Depth rule](02-visual-grammar.md)), except reaction backdrops (`mood`, `burst`) and title cards.

## 6. Timing

1. **Word = event.** Put each pop, snap, swap or punch on the key word (±0.3 s; ±0–0.3 s in shorts). Text arrives 0.3–1.0 s after the cut.
2. **Count events, not cuts.** The references cut 7–17 times a minute in both formats; what keeps them alive is a new visual event every 1.5–3 s inside the shot. A 15 s map shot with five events is better than five 3 s shots of the same map.
3. **Hold before the hit.** Long innocent holds make impacts land: a crossing guard holds 3.1 s before the van crosses in 5 frames (WW2 7:20); a hammer is held 33 frames before a 2-frame fall (Fact-check 17:24); a blade tip creeps in, withdraws, 18 frames of stillness, then a 3-frame swing (Greek myth 1:44).
4. **Snap, then hold.** Poses and expressions change in 1–2 frames and hold 1.5–3 s. Exception: a realization can be a slow burn (eyes widening over about 4 s, China 15:14).
5. **Climax cadence.** Fights and arguments cut every 0.1–1.6 s; then hold the outcome 2–4 s. The Greek myth climax: 4- and 4-frame cuts, a 35-frame letterboxed close-up of the monster's eye, a 7-frame reaction, a 2-frame snap, a 20-frame hold. Not every climax speeds up: the Rome ambush gets heavier through content, with 1.7–8.8 s shots.
6. **Empty frames are beats.** 2–3 s of an empty set after a death or an escape (China 9:52, 10:28, 26:30); 1 s of black before a solemn title; an exit that leaves the composition for 0.7–1 s (Rome).
7. **Deflate** comic or ordinary peaks within 2–6 s; never deflate atrocity beats ([07 §5](07-story-craft.md)).

### 6.1 Coverage: shot sizes, continuous motion and density (painted look)

The reference films rarely hold one medium-wide framing: they cut between an establishing wide, a gesture at medium, a reaction close-up and an over-the-shoulder pair, and something always moves. Plan this per shot before choosing layers, and write the size into the shot card (below).

**Shot-size quotas** (count per minute of film, from the `camera.frame` sizes of each shot's main key):

| Size | Quota | Use it for |
|---|---|---|
| `ews` / `ws` | 1–3 per place or era change | The establisher: a Places 2.0 landscape or `set`, a real `geo` map (country by `iso`, region by `lonlat`), an `ortho` globe that spins to the place. A high `angle` makes the figure small and lost |
| `ms` | the gesture beats | A character doing the action with the set around them; `follow` a walker or a car |
| `mcu` | the reaction and dialogue beats (does not count toward the close-up quota) | Reactions, the speaker in an `ots` pair |
| `cu` | **at least 25 %** together with `ecu` | Decisions, a name card, the line that matters; faces get `detail` automatically when they are large |
| `ecu` | 1–3 per minute | The stare, the scream, the object that changes everything (the bottle, the coin); add `letterbox` and an `overshoot` dolly |
| `ots` | every exchange between two characters | `frame` keys `{target: speaker, ots: listener}`, swapped on the reply (shot-reverse-shot inside one shot); a `whip` between the keys for a fast retort |

Rules of thumb: never three cuts in a row at the same size (the density lint warns); punch from `ms` to `cu` on the key word (`overshoot` 0.12–0.18) instead of a flat `camera.punch` when a face is the subject; open every new location or era wide, and every new character at `ms` or tighter.

**Every shot has one continuous motion.** Breathing and the default drift are not enough. Pick one thing that moves for the whole shot: a vehicle, a walker or an animal on a `path` (with exhaust, dust or a gait), `particles` (smoke from a chimney, gas from a bottle, dust motes in a window shaft), a `follow` or `handheld` camera, a `frame` move between two sizes, a spinning globe, a map `flood` or `drawOn`, a machine part (`gears`, `piston`). Then add the hold-and-snap beats on top of it.

**Hold-and-snap still governs poses.** Continuous motion lives in the world and the camera; characters keep holding a pose and snapping to the next one on the key word (the painted `acting` adds anticipation and settle). A character never drifts slowly between two poses unless it is a deliberate slow burn.

**Density checklist per shot** (the validator prints the lint; every warning is fixed or justified in the shot's `screen` note):

1. Three planes: a place (never `void`), actors, a foreground element (`fg`, a `set` layer, `silhouettes`, an `ots` shoulder, a near prop at `z` > 1).
2. The light is set: `style.light` for the film, a shot `light` or `grade` for a mood change, a practical source in the set (window shaft, lamp, fire).
3. One continuous motion (above).
4. Shot size differs from at least one of the two previous shots.
5. Maps are real geography (`geo` + `iso` / `lonlat` / `continent`), animated (`flood`, `drawOn`, `wipe`, routes, tokens), not blobs.
6. Text is lettering on `hud` when the camera frames tightly, so it stays readable.

## 7. The shot card

Before writing layers, fill one card per shot. Keep it in the storyboard's `- On screen:` line or as the shot's `screen` field:

```
kNN · 3.4 s · key word "rings" @ 2.2
Learns:   frozen molecules lock at fixed angles
Happens:  six molecules pop into a ring one by one; a title RINGS lands
Changes:  the crowd has become a structure with a hole in it
Because:  k05 made them slow down and hold hands -> what shape do they make?
Device:   10-technique-library M4 (a diagram figure comes alive) + pops 0.3 s apart
Size:     ms -> cu on "rings" (overshoot); continuous motion: the molecules jostle (path loops)
```

A shot is ready only if all four lines are filled:

- **Learns:** one idea, in viewer words.
- **Happens:** what physically moves on screen (subject + verb + visible result).
- **Changes:** the state at the end differs from the state at the start (position, size, colour, count, owner, mood, costume, what exists).
- **Because:** why this shot follows the previous one: it shows the effect of a cause, answers a question, reverses an expectation, raises the stakes, or returns to a callback. If you cannot write it, reorder or merge shots.

Distinguish **an editing cut** from **a new story event inside a continuing shot**. A map spine, a board or a stage holds the framing while events change it; cut only when the viewpoint, the place or the time changes.

## 8. Combining techniques into complete scenes

A scene is 2–8 shots built around one meaning event. These patterns recur across the references; each step names the device, and [10-technique-library.md](10-technique-library.md) has the measured version.

**Mechanism scene** (how something works). 1. The normal state, alive (a crowd jostling). 2. The trigger, on its key word (the grade turns cold). 3. The hidden step made visible by characters (arms sprout, hands link). 4. The new structure, built in staggered pops 0.3 s apart. 5. A label names it, after the viewer has seen it. 6. The consequence in a new place. *Example: `examples/vertical_short` k04–k08.*

**Rule broken** (hook). 1. The rule, shown in under a second. 2. The same set and framing (callback composition), the exception happens on the key word, a witness snaps to `shock` on the same frame. 3. The question in one line. *k01–k03.*

**Escalation ladder.** 1. Request one: a small reaction. 2. Request two, same framing: a stronger reaction (facepalm). 3. Request three: the line is cut off mid-word, a hard cut to the consequence. Keep the repeated line identical so the viewer predicts it (WW2 "Daddy, I want X").

**Cause → effect in one frame.** The cause object enters (a bag of coins, a strike-through, a hose); the effect happens in the same composition within 1–2 s; hold the result 1 s. Then cut to its wider consequence (the map recolours).

**Off-screen consequence** (death, destruction, violence). 1. Show the threat clearly (the raised sword, the creeping blade). 2. Cut away before contact: a black beat, a wall edge, a dust puff, a ghost fade, a coffin dropping in 6 frames, an ECG going flat. 3. Hold the aftermath silently, 3–12 s. 4. A stand-in object carries the number (a labelled block, crosses on a region).

**Before / after callback.** Reuse an exact earlier composition with one change: the grade, the dressing, the owner, the age, the costume. The viewer reads the change because everything else stayed. (Same piazza regraded grey; the bunker map empty then full; the storehouse full then cobwebbed.)

**Comparison stack.** Two earlier shots frozen side by side or top/bottom (`panel` `split` / `custom` with `{shot, t}`), one number or label on the seam, a punch when it lands.

**What-if.** A `flash-cut` or `negative` beat on "if", the same set turned against the subject (frozen, empty, burning), a silent title, then back to reality.

**Chapter return.** Every 60–90 s in a long film, return to the hub (host room, museum, map spine) in its current state: the counter sign increments, the HUD chip changes ("FREE FOR ALL", "HAN 2"), the viewer stand-in gets a sticker. This both resets attention and keeps continuity.

**Payoff.** End on an image that answers the central question with an object the viewer already knows (the drink's ice cube as "a tiny lid"), then stop. Shorts stop 0.3 s after the last word; long films may add a cliffhanger or a tease.

## 9. Check before rendering

Run these on the storyboard, then on the `--sheet`:

1. **Question test:** the first 10 s (shorts: 3 s) state or show the central question.
2. **Spine test:** read only the "Changes" lines in order: they tell the whole story without narration.
3. **Because test:** every shot's "Because" names the previous shot or an open question.
4. **Event density:** no shot runs longer than 4 s (shorts) or 8 s (long films) without a new event inside it.
5. **Word sync:** each key word has an event within ±0.3 s.
6. **Continuity:** persistent state (counters, damage, stickers, costumes, set states) is the same in every later shot; callbacks match their original framing.
7. **Readability:** labels 56+ (shorts 46–70), faces not covered, text inside the frame or the vertical strip.
8. **Sensitive material:** no gore, no extremist symbols, no real logos or likenesses ([07 §5](07-story-craft.md)). The reference videos sometimes draw such symbols and more explicit violence; this skill deliberately does not.
9. **Coverage:** per minute at least 25 % `cu`/`ecu`, an `ots` pair for every dialogue, a wide establisher per place or era; the density lint prints no warning that is not justified (§6.1).
10. **Vocabulary:** `python3 scripts/spec.py film/spec.json` passes; render `--sheet` and `--stills` on risky shots and look at them.

## 10. Transfer: the same method on other topics

The method does not depend on history. Five worked outlines (central question → arc → meaning events → the action that shows each one):

**A. "Why ice floats" (science, vertical short, built: [`examples/vertical_short`](../examples/vertical_short/spec.json)).** Broken-rule arc. Things shrink when frozen (a candle shrinks) → water expands (an ice cube lands on a mug, the professor gasps) → liquid is a crowd (jostling `obj` discs) → cold makes them hold hands (grade `cold`, arms sprout) → rings leave empty space (staggered pops, EMPTY SPACE in the hole) → +9 % volume (stacked comparison) → less dense, it rises (an ice block `move`s up) → a lid on the lake (a `whip` that rises to the surface, blocks drop in) → life survives below (a `whip` back down, thumbs-up, 4 °C counter) → what if it sank (`negative` flash, `freeze`) → payoff on the drink (`photo` frame, `mono`).

**B. "How does a vaccine train an army for an enemy it has never met?" (biology, 60–90 s).** Mechanism arc. The body's guards are a crowd of beans with no idea what the enemy looks like (`crowd`, `marks` `question`) → the vaccine delivers a harmless "wanted poster" (`doc` `poster` slides in on "vaccine") → guards study it and build matching weapons (a `pictobubble` of the poster, `pose:"hammer"` + props popping) → memory cells file the poster (a `doc` `idcard` stamped `stamp` "SAVED") → months later the real enemy arrives (`timeskip`, a villain `obj` with `menace`) → the guards recognise it instantly (a rack `focus` from the poster to the villain, `expr` snap) → it is removed before the body notices (`exit:"zip"`, the host sleeps through it: `sleep-drool`, `marks` `zzz`). Payoff: the poster on the wall in the closing frame.

**C. "Why does printing more money make everyone poorer?" (economics, long chapter).** Escalation ladder + cause → effect. A baker sells bread for 1 coin (`bean` + `bread` + `counter`) → the ruler prints a stack of coins (`crt`/prop + `paperstorm`) → everyone has twice the coins, the baker doubles the price (same composition, `swap` on the sign text) → round two, three, the price `counter` races (`hud` `meter` to the warning line) → the coin becomes worthless (a `coin-heap` used to light a stove, `fire`) → the chart crashes (`prop` `easel` with `chart: {pts, crashAt}` + `camera.shake`). Running device: a `hangsign` "PRICE OF BREAD" that swaps each round.

**D. "How can a stranger guess your password?" (technology, vertical short).** Case loop. Claim: "8 characters is safe" (a `doc` `checklist` with a tick) → the attacker is a bored bean at a terminal (`monitor`, `sleepy`) → a guess counter spins (`hud` `counter` with `value` keys) → common words fall first (labels popping and getting struck) → a long passphrase: the counter crawls, the attacker ages (`swap` `look:{age:"elder", beard:"long"}` under a `poof`) → verdict `stamp` "SAFE". Ending: loop back to the first checklist, now crossed out and rewritten.

**E. "Why do bridges sway?" (engineering, 2 min).** Mechanism + what-if. Marching soldiers cross a bridge in step (`crowd` `march`) → each step is a small push (`camera.shake` per step, a pendulum `swing` on a hanging sign) → pushes in rhythm add up (`swing` `amp` grows) → the bridge bucks (`jitter`, `pose:"cheeks"` faces) → the order "break step!" (`doc` `pictobubble` `shout`) → the swing dies away (`swing` `decay`) → modern bridges add dampers (a `prop` on a cut-away with a label). What-if: the same bridge without breaking step, `negative` flash, the sign falls (`exit:"pivot-fall"`).

In each case the history-specific props are replaced, but the arc, the event marks, the shot card, the timing rules and the scene patterns stay the same.
